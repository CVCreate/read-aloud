# 念念读给你 · 服务于识字阅读困难人群的小程序

**简体中文** | [English](README.en.md)

把任何一段文字，变成一个绿色的大按钮。给不识字、眼花、看不清小字的人用。

---

## 一、最快跑起来（3 步）

> 📌 **说明**：微信同声传译插件未对个人主体开放，因此本项目不使用该插件，改走云函数 + 腾讯云 TTS。
> **本项目已全面切换到云函数 + 腾讯云 TTS 方案**，不再依赖该插件。
> 将来若换成企业主体，可参考文末「附：企业主体的省钱路线」。

### 第 1 步：导入项目

微信开发者工具 → 导入项目 → 选择本目录。
首次导入填入自己的小程序 AppID。也可把 `project.config.example.json`
复制为 `project.config.json`（后者含真实 AppID，不入版本库）。

### 需要自己准备的三项配置

| 配置 | 放哪里 | 是否入库 | 说明 |
| --- | --- | --- | --- |
| 小程序 AppID | `project.config.json` | 否，模板 `project.config.example.json` | 复制模板后填入自己的 AppID |
| 云开发环境 ID | `miniprogram/config/local.js` | 否，模板 `local.example.js` | 单环境可留空，走默认环境 |
| 腾讯云密钥 | 云函数环境变量 | 否，不落在代码中 | 见下面第 2 步 |

```bash
cp project.config.example.json project.config.json
cp miniprogram/config/local.example.js miniprogram/config/local.js
```

`local.js` 不存在时程序也能运行，`config/index.js` 会静默回退到默认值。

### 第 2 步：开通云开发 + 部署云函数（**必做**，朗读全靠它）

1. 开发者工具左上角点「**云开发**」→ 开通（个人主体可开通，有免费额度，选基础版即可）
2. 分别右键 `cloudfunctions/tts`、`cloudfunctions/ocr`、`cloudfunctions/asr`
   →「**上传并部署：云端安装依赖**」（`asr` 是语音输入用的，不部署则 🎤 不显示）
3. 云开发控制台 →「云函数」→ 选中函数 →「配置」→「环境变量」，三个函数都加：

| 变量名 | 值 |
|---|---|
| `SECRET_ID` | 腾讯云 CAM 密钥 ID |
| `SECRET_KEY` | 腾讯云 CAM 密钥 Key |

> ⚠️ 变量名**不能**以 `SCF_` / `QCLOUD_` / `TENCENTCLOUD_` 开头，
> 云开发会直接拒绝保存（实测报错 `InvalidParameterValue.Environment`）。
> 就用上面这两个名字。

密钥在 [腾讯云控制台 → 访问密钥](https://console.cloud.tencent.com/cam/capi) 获取。
**务必新建子账号密钥，只勾 TTS + OCR + ASR 三个权限，不要用主账号密钥。**

| 云函数 | 用途 | 需要的腾讯云权限 |
|---|---|---|
| `tts` | 朗读（合成语音） | `QcloudTTSFullAccess` |
| `ocr` | 照片识字 | `QcloudOCRFullAccess` |
| `asr` | 语音输入（说话） | `QcloudASRFullAccess`（一句话识别） |

4. 验证：云开发控制台 →「云函数」→「日志」，调一次 `tts`，返回 `ok: true` 即通

### 第 3 步：预览

点「预览」，扫码真机试。**朗读和识字都要真机验证。**

> 没配密钥时程序也能打开、能打字、能存历史，只是点「念给我听」没声音
> （设置页「功能状态」会显示云开发未开通）。

## 四、断句引擎怎么调

改 `miniprogram/config/index.js`：

```js
softSentenceLen: 45,   // 超过多少字，就按逗号再切一刀
maxSentenceLen: 100,   // 硬切上限（腾讯云 TTS 单次上限 110 字，别超过）
```

断句规则全在 `utils/sentence.js`。改完**必须**跑一遍回归测试：

```bash
node tests/sentence.test.js
```

29 项断言，覆盖：基本断句、二次切分、硬切兜底、丢字检测、数字处理、
符号净化、边界情况、真实场景（微信消息 / 药品说明书）。
退出码 0 = 全通过，1 = 有失败。

> 丢字检测是硬指标：所有片段拼回去必须等于净化后的原文。
> 改断句逻辑时这条最容易踩。

## 五、常见问题

**Q：点「念给我听」没声音？**
A：按顺序查 —— ① 手机音量要 >0（已设置静音模式也播放）② 开发者工具控制台看有没有「cloud 未开通」警告 ③ 设置页「功能状态」云开发是不是红的 ④ 云函数日志里看 `tts` 返回的具体原因。

**Q：开发者工具编译报「插件 wx069b... 不存在」？**
A：说明 `app.json` 里残留了插件声明。当前代码已清空（`"plugins": {}`），确认没有手动加回去。

**Q：粘贴没反应？**
A：看是不是没同意隐私保护指引。小程序后台 →「设置」→「服务内容声明」→「隐私保护指引」，把剪贴板、相册、麦克风勾上并发布。

**Q：拍照识字一直说没开通？**
A：`ocr` 云函数没部署，或环境变量没配。云函数日志里有具体原因。

**Q：看不到「🎤说话」按钮？**
A：说明云开发没开通，或 `asr` 云函数没部署。按钮是按能力探测结果显示的，
部署后重进小程序就会出现。

**Q：退到微信聊天后还在念，怎么停？**
A：这是有意设计（后台继续念）。回小程序点红色大按钮即可停；
微信顶部也会留一个返回小程序的入口，点它回来再停。

**Q：念到一半卡住？**
A：单句合成失败会自动重试一次，再失败就跳过继续下一句，不会整段卡死。结束时会语音提示有几句没念出来。

**Q：第一次打开看到的引导页，后来想再看？**
A：设置页最下面「重新看一遍使用说明」。

## 六、附：企业主体的省钱路线（将来可切换）

如果这个小程序以后转成企业主体，可以切回微信同声传译插件（零密钥、免费额度更大）：

1. 后台「设置 → 第三方设置 → 插件管理」搜索并添加「微信同声传译」插件
2. `app.json` 里把 `"plugins": {}` 改回：
   ```json
   "plugins": {
     "WechatSI": {
       "version": "后台显示的版本号",
       "provider": "<插件 AppID>"
     }
   }
   ```
3. `config/index.js` 里 `ttsEngine` 改回 `'plugin'`

代码层已做能力探测（`utils/tts.js` 的 `probe()`），两条通道随时可切，页面不用改。

## 七、界面约束（改样式前先看）

1. 按钮最小高度 96rpx，主按钮 240rpx 圆形
